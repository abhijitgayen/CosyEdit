# CosyEdit / CosyVoice Lightweight Rust Runtime

This directory contains an optimized, lightweight, cross-platform Rust runtime server implementation for **CosyEdit** and **CosyVoice**.

---

## 🚀 Why Rust Runtime?

1. **High Concurrency & Low Latency**: Built on Rust's async runtime (`tokio`), web server framework (`axum`), and gRPC framework (`tonic`). It supports non-blocking concurrent request handling without Python GIL overhead.
2. **Device & Platform Universal Support**: Compiles into a single self-contained binary across Linux, macOS, Windows, x86_64, ARM64, and embedded/edge devices.
3. **Zero-Copy Streaming**: Audio chunks generated by inference pipelines are streamed directly to clients (via HTTP Chunked Transfer / gRPC Streaming) with minimal memory allocation and lower latency.
4. **Flexible Request Routing & Proxying**: Acts as a high-throughput load balancer/proxy in front of Python or Triton/TensorRT-LLM worker backends, or as an ONNX execution runtime engine.

## 🛠️ Features & Endpoints

The Rust runtime mirrors all original Python/gRPC service APIs and adds CosyEdit speech editing capabilities:

| Endpoint | Method | Description |
|---|---|---|
| `/inference_sft` | `POST / GET` | Synthesize speech using pre-trained SFT speaker ID. |
| `/inference_zero_shot` | `POST (multipart)` | Zero-shot voice cloning with prompt text and audio. |
| `/inference_cross_lingual` | `POST (multipart)` | Cross-lingual speech synthesis with prompt audio. |
| `/inference_instruct` | `POST` | Instruct-guided speech synthesis with speaker ID. |
| `/inference_instruct2` | `POST (multipart)` | Instruct-guided speech synthesis with prompt audio. |
| `/inference_edit` | `POST (multipart)` | End-to-end multi-span speech editing (target text, original text, original speech). |
| `CosyVoice/Inference` | `gRPC Stream` | High-efficiency bidirectional/streaming gRPC service endpoint defined in `cosyvoice.proto`. |

## 📦 Building & Running

### Prerequisites

- **Rust toolchain** (`cargo` / `rustc` 1.70+)
- **Protobuf compiler** (`protoc`)

### Build

```bash
cd runtime/rust
cargo build --release
```

### Run Standalone Server

```bash
./target/release/cosyedit-runtime --port 50000 --grpc-port 50001
```

### Run as High-Performance Proxy to Python/Triton Backend

```bash
./target/release/cosyedit-runtime \
  --port 50000 \
  --grpc-port 50001 \
  --backend-url http://127.0.0.1:8000
```

## 📝 Examples

### HTTP Request Example (Speech Editing)

```bash
curl -X POST http://127.0.0.1:50000/inference_edit \
  -F "target_text=Hello world" \
  -F "original_text=Hello friend" \
  -F "original_speech=@/path/to/original.wav" \
  --output edited.wav
```
